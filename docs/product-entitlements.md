# JMN Media Partner: proposed product entitlements

Status: internal product design only. No runtime imports, provisioning, billing,
SuiteDash visibility changes or production enforcement are part of this sprint.
The accompanying JSON is an example contract, not a live access policy.

**Limit cost, not habit.** Everyday planning, reviewing and organizing should stay
easy. Meter costly execution through explicit allowances, provider costs and
commercially reviewed add-ons. Never represent an unresolved allowance as unlimited.
No final numerical seat, workspace, usage or storage limits are set here.

capabilities are roadmap entries, not current access or delivery promises.

## Future policy contract

Keep product eligibility separate from authorization and resource ownership:

1. A commercial plan identifies eligible capabilities and allocation policy IDs.
2. A server-owned workspace entitlement resolves plan defaults, grandfathered beta
   access, explicit grants, approved add-ons and temporary overrides.
3. Capability checks remain subordinate to verified contact/company membership,
   project ownership, active template grants and existing session validation.
4. SuiteDash menu visibility consumes a safe capability summary. Every app/API
   independently authorizes requests. Menus never grant access.
5. Cost allowance consumption would occur atomically on the server immediately
   before expensive work; navigation and ordinary habit are not usage events.

Represent quantitative limits as `unresolved` until approved, then as an explicit
finite allocation policy with a unit, reset window and exhaustion behavior. Null,
missing and zero must never mean unlimited. A production policy resolver must
reject unresolved paid-execution policies rather than grant speculative access.
No resolver or usage ledger is implemented here, and existing beta access must
not be disabled by merely assigning one of these proposed tier names.

Any later rollout requires reviewed policy versions, explicit grandfathering,
tenant-isolation tests, server enforcement and a staged migration/visibility plan.
Google, TikTok, LinkedIn, Higgsfield, Stripe and public trial are not implemented.
